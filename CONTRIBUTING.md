# Contributing to Areopagus

The project needs more than code. If you can do any of the following, you are welcome:

- **Developers:** TypeScript, PostgreSQL/PostGIS, maps (MapLibre), ActivityPub, accessibility, offline-first PWA
- **Translators:** interface and content, any language
- **Historians and theologians:** curating events, narratives and sources, especially for the first millennium
- **Editors:** proofreading and structuring public-domain texts for the library
- **Security specialists:** threat modelling and guidance for users in countries where Christians are persecuted
- **Community people:** parishes, missions and diaspora communities willing to try early versions

## How to start

1. Read the [README](README.md) and the [Code of Conduct](CODE_OF_CONDUCT.md).
2. Open an issue describing what you want to work on before a large change.
3. Keep pull requests small and focused.

## Data and texts

Only add texts that are in the public domain or under an open licence, and record the source and licence with every text. When in doubt, open an issue first.

## Language

Code, commits and issues are in English. Discussions may be in any language; say which one you are writing in.
